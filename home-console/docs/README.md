# Home Console

One parametric desktop device, with media closures and printed shell parts.
The default and `archetype-*` presets describe original constructions. Named
presets assert sourced envelopes and counts; their styling remains archetypal.
Read [NOTICE](../NOTICE) for provenance.

## Frame and catalog mapping

| Parameter | Axis | Reference field |
|---|---|---|
| `body_width` | X, centered | `dimensions_mm.states.body.width` |
| `body_depth` | Y, front at −D/2 | `dimensions_mm.states.body.depth` |
| `body_height` | Z, flat underside at 0 | `dimensions_mm.states.body.height` |
| `orientation_tilt_deg` | rotate about the bottom right Y edge | 90° for a vertical-only published state |

A vertical-only reference is laid flat internally: vertical height becomes
width, vertical width becomes height, and depth stays depth. Rotating it 90°
restores the published orientation. The `envelope` excludes projecting feet,
handles and removable covers in their displaced poses; those remain visible in
`console` mode. AABB checks of the envelope use the corresponding published
state. Shell parts use their print pose, while the assembled parts are tilted.

## Modes and composition

| Mode | Parts | Purpose |
|---|---|---|
| `console` | body, closure | assembled preview; side covers are separate solids |
| `envelope` | envelope | single fused fit hull |
| `top_shell` | top_shell | hollow upper print part |
| `bottom_shell` | bottom_shell | hollow lower print part |
| `media_door` | media_door | print-posed lid, tray, door, flaps or blank |

| Component module | Construction | Interfaces |
|---|---|---|
| `console_shell` | ruled loft, raised tier, side covers | device_envelope, cradle_seat, mounting_surface |
| `console_shell` | vent fields, feet, stand seat, handle | stand_seat, grip_surface |
| `console_io` | cartridge/card slot, lid, tray, slot loader | media_slot, revolute_axis, prismatic_axis |
| `console_io` | controller openings, port rows, switches | connector openings |
| `connectors`, `controls`, `displays` | receptacles, button row, display recess | existing shared components |

`family.py` is authored. `main.py` is generated by
`python3 tools/inline_parts.py --write home-console`; never edit the generated
file. New component text lives in `commons-lib/hardware/console_shell.py` and
`console_io.py`. Cutters overshoot their faces by at least 1 mm, and fused
features overlap by 0.2 mm. A CDG interface expresses design intent; no physical
mating proof or electrical functionality is claimed.

## Presets and archetype rules

`tools/presets/home_console.py` reads the keystone catalog at `SPEC_PIN`.
Generated provenance records the catalog digest and fallback groups; unresolved
envelopes produce an `awaiting_a_source` entry instead of a named preset.

| Archetype preset | Construction exercised |
|---|---|
| default | stepped body, top cartridge slot and flaps |
| wedge cartridge | wedge profile and panel slide switches |
| front loader | front cartridge door |
| card console | thin front card slot |
| lid disc | crowned slab and hinged lid |
| cube disc | compact body and fused handle |
| tray disc | concave sides and sliding tray |
| slot disc | crowned, skewed slot loader |
| tower disc | side covers and cradle seat |
| upright display | integrated front screen and rear cartridge |
| mini | no media, compact slab |
| add-on disc | host link and tray |

The body plan is our rule: sourced screen selects upright, a handle selects
cube, standing or tall dimensions select tower, otherwise slab. Named products
are never assigned a body shape by tracing photos. Corner radii are 6% of the
smaller footprint axis and 8% of height; wall thickness is 2.5 mm, seam height
45% of the low section, and the seam groove is 0.8 mm. The stepped tier is 38%
of body height; wedge front and upright rear heights are 55% and 45%.
Vents, feet, control positions, connector openings and media clearances are our
archetype constructions, even where the presence or count is sourced. Port
outlines are generic keep-outs, not connector manufacturing specifications.
The source module documents every additional rule.

Animations interpolate live parameters: lid opening, tray ejection, standing
orientation and cover displacement. Their geometric movement does not certify
clearance against other components. The default media type determines which
closure visibly moves; select the appropriate archetype before animating it.

## Awaiting a source

Unpublished device envelopes remain unresolved. Published envelopes do not
supply wall thickness, media seating depth, panel positions, precise connector
shapes, vents or a maker's shell profile. These stay archetypal, with the
catalog-derived preset fallback list naming the unknown fact groups. The
measurement queue is maintained separately from these public design files.

### Front slot and control separation

The original horizontal slot-loader layout keeps the front power/reset/LED row
at least 1 mm of material above the slot lip. This avoids tangent cavity edges
at thin source envelopes such as the Wii's 44 mm body. The lip size, control
positions and this material gap are archetype rules; the published envelope and
sourced control counts do not change. No manufacturer's panel layout or physical
fit is asserted. Tall bodies whose drive mouth rotates upright keep their
existing row rule.
